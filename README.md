# Modern Developer Portfolio

A modern, professional, ATS-friendly developer portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features

- ✨ **Modern Design** - Luxury UI with smooth animations
- 📱 **Fully Responsive** - Works on all devices
- 🌙 **Dark/Light Mode** - Theme toggle support
- ⚡ **Fast Performance** - Built with Vite
- 🎨 **Beautiful Animations** - Framer Motion animations
- 📊 **Multiple Sections** - Hero, About, Skills, Experience, Projects, Education, Certifications, Achievements, Contact
- 🎯 **ATS-Friendly** - Optimized for applicant tracking systems
- 📝 **Easy to Customize** - JSON-based data layer

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Fast build tool
- **Tailwind CSS** - Utility-first CSS
- **Framer Motion** - Animation library
- **Lucide React** - Icon library

## Quick Start

### Installation

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```

## Customization

Edit `src/data/portfolio.json` with your information including profile, skills, experience, projects, education, certifications, and achievements.

## Project Structure

```
src/
├── components/          # React components
├── hooks/               # Custom React hooks
├── data/                # Data layer (portfolio.json)
├── types/               # TypeScript types
├── App.tsx
├── main.tsx
└── index.css
```
